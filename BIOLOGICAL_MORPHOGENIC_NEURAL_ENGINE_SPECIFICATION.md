## 1. Фундаментальна концепція та філософія архітектури

Сучасний підхід до ШІ (LLM на кшталт GPT-4 чи Llama) зайшов у глухий кут:
1. **Змішування "Процесора" і "Жорсткого диска":** У звичайних моделях 90% ваг — це пасивна енциклопедія (факти з Вікіпедії, дати, код), розмазана по мільярдах параметрів. Через це вони гігантські, повільні та споживають кіловати енергії.
2. **Мертва статичність:** Модель не має внутрішнього часу, не може змінювати свою топологію і обнуляється після кожного згенерованого токена.

### Наша парадигма:
* **Старт з одного нейрона (Minimal Genesis):** Ми не прописуємо архітектуру руками. Модель починається з однієї клітини, яка ділиться, мутує та ускладнюється (Complexification) під тиском середовища.
* **Розділення Мислення та Пам'яті:** Живе ядро (100 000 гетерогенних нейронів) — це **чистий когнітивний процесор**. Воно не тримає в собі всю фізику чи історію світу, а володіє мета-навичками: як формувати концепти, як записувати їх у пластичний блок пам'яті і як проводити ментальну симуляцію.
* **Природна модульність (Цитоархітектоніка):** Завдяки фізичному правилу «вартості зв'язку», мережа самостійно утворює функціональні частки (аналоги лобової частки, зони Брока, скроневої кори) з різною внутрішньою щільністю (від 3 зв'язків до 2000 на нейрон).

## 2. Апаратна фізика: Чому CPU Zen 3 (Ryzen 5 5600) + Tokio

### 2.1. Чому не класичний GPU на старті?
* Відеокарта (GPU) побудована на парадигмі **SIMT (Single Instruction, Multiple Threads)**: блоки по 32 ядра (Warp) зобов'язані робити одну й ту саму операцію в один такт часу над прямокутними щільними матрицями.
* Для живого, нерегулярного, асинхронного графа з різними функціями активації GPU зазнає критичного штрафу розгалуження (branch divergence) та затору шини пам'яті (memory bottleneck).

### 2.2. Суперсила Ryzen 5 5600 та 32 МБ L3-кешу
* **Легкотривкі Актори Tokio (Green Threads):**
  * Завдання в Tokio (`tokio::spawn`) важить усього ~250–500 байт.
  * У 1 ГБ RAM поміщається понад 1 000 000 сплячих акторів.
* **Зона ультра-швидкості (L3 Cache Sweet Spot):**
  * Ryzen 5 5600 має єдиний монолітний кристал L3-кешу об'ємом **32 МБ** із затримкою доступу всього **~10–12 наносекунд** (проти 65 нс у звичайній DDR4).
  * Мережа з **50 000 – 100 000 активних акторів-нейронів** повністю поміщається всередині кристала процесора, досягаючи пропускної здатності в **10–30 мільйонів повідомлень/сек** на 12 апаратних потоках без виходу на шину материнської плати.

## 3. Анатомія Мережі: Сіра та Біла Речовина

Архітектура будується на двох фундаментальних компонентах біологічного мозку:

```
    [ Кластер Логіки (Лобовий) ]                  [ Кластер Пам'яті (Скроневий) ]
    (Сіра речовина: 3-5 зв'язків)                 (Сіра речовина: 1000-2000 зв'язків)
                │                                                ▲
                │          ┌───────────────────────────┐         │
                └─────────►│  Біла Речовина (Highway)  ├─────────┘
                           │  Багатосмугова шина зв'язку│
                           │  (Швидкісний Нервовий Тракт│
                           └───────────────────────────┘
```

### 3.1. Сіра речовина (Локальні обчислювальні кластери)
Кожен нейрон є гетерогенним об'єктом зі своїми унікальними параметрами:
* **Індивідуальна стала часу ($\tau_i$):** Швидкі нейрони сприйняття (затухання 2 мс) та повільні нейрони контексту (утримання 10 секунд).
* **Адаптивний поріг чутливості ($V_{th}$):** Забезпечує сенсорне звикання до постійного шуму.
* **Власна пластичність:** Різні швидкості адаптації за правилом Хебба.

### 3.2. Біла речовина (Швидкісні канали зв'язку / Нервові Тракти)
* Замість мільйонів хаотичних довгих ниток алгоритм утворює **Високошвидкісні Магістралі (Neural Highways)**.
* **Мієлінізація:** Канали з найвищим трафіком оптимізуються рантаймом Rust (переводяться в атомарні безблокувальні кільцеві буфери `Lock-Free RingBuffer` у кеші L3). Затримка передачі падає практично до нуля.

## 4. Самозбірка Часток Мозку (Connection Cost Principle)

Ми не кодуємо вручну «зону мовлення» чи «зону пам'яті». Вони виникають самі за рахунок **функції пристосованості з урахуванням вартості зв'язку**:

$$\text{Fitness} = \text{Точність (Accuracy)} - \lambda_1 \sum \text{Довжина синапсів} - \lambda_2 \sum \text{Кількість зв'язків}$$

### Результат еволюційного відбору:
1. **Лобова частка (Prefrontal Logic):** 
   * **3–6 зв'язків на нейрон.**
   * Розріджена топологія, функція маршрутизатора та логічного вентиля. Запобігає «каші» та самозбудженню.
2. **Скроневий Блок Пам'яті (Temporal Association Lobe):**
   * **1 000 – 2 000 зв'язків на нейрон.**
   * Надщільний кластер, що працює як голографічна асоціативна пам'ять (Attractor Network). Зв'язує фізичні явища, абстракції та математичні формули в єдиний резонансний акорд.
3. **Зона Брока (Broca Speech Motor Area):**
   * Середня/висока щільність зв'язків.
   * Перетворює сирий резонанс думки у граматично структуровану мовну послідовність.

## 5. Механізм вивчення дисциплін (Приклад: Фізика та 3-й закон Ньютона)

Мозок вчать фізиці не вшиванням формул у код, а через три когнітивні мета-операції:

```
[Запит: "Третя формула Ньютона"]
              │
              ▼
   ┌──────────────────────┐
   │ Лобова Частка (Core) │ ──(1. Розуміння наміру: потрібен закон взаємодії)──┐
   └──────────────────────┘                                                    │
              ▲                                                                │
              │                                                                ▼
              │ (3. Повернення асоціації:          ┌─────────────────────────────────────────┐
              │     F12 = -F21, вектор сил)        │         БЛОК АСОЦІАТИВНОЇ ПАМ'ЯТІ       │
              │                                    │                                         │
              └────────────────────────────────────┤ * Вузол "Ньютон"                        │
                                                   │ * Кластер "Дія та протидія"             │
                                                   │ * Формула: F1 = -F2                     │
                                                   └─────────────────────────────────────────┘
              │
              ▼
   ┌──────────────────────┐
   │  Зона Брока (Мова)   │ ──(4. Синтез мови: "Сила дії дорівнює силі протидії...")
   └──────────────────────┘
```

1. **`WRITE_CONCEPT` (Створення концепту):** Під час пояснення закону в Блоці Пам'яті брунькуються вузли сутностей (`[Сила 1]`, `[Сила 2]`, `[Знак мінус]`).
2. **`BIND_RELATION` (Встановлення зв'язку):** Нейрони пам'яті сплітаються у синаптичний контур рівності та протилежності напрямків.
3. **`QUERY_SIMULATE` (Запит та ментальна симуляція):** Ядро витягує зв'язок на «робочий стіл» уваги, перевіряє фізичні обмеження (наприклад, збереження імпульсу) і передає готовий висновок у мовний апарат.

## 6. Двоетапний Морфогенез: Від сліпих мутацій до Нейро-Садівника

### Етап I: Випадкові мутації та збір телеметрії (NEAT-подібний генезис)
* Початковий стан: 1 сенсорний вузол $\rightarrow$ 1 прихований нейрон $\rightarrow$ 1 вихідний вузол.
* Доступні атомарні мутації:
  * `AddConnection(from, to, weight)`
  * `SplitConnectionWithNeuron(conn_id, activation_function)`
  * `MutateNeuronParameters(tau, threshold, activation)`
  * `CreateHighwayChannel(cluster_a, cluster_b)`
  * `MyelinateChannel(highway_id)`
  * `PruneDeadElements(threshold)`
* Логування кожного кроку в базу телеметрії:
  $$\mathcal{D} = \{ (S_t, \text{Mutation}_t) \rightarrow (S_{t+1}, \Delta \text{Loss}, \Delta \text{Latency}, \Delta \text{Energy}) \}$$

### Етап II: Модель-Архітектор (Нейро-Садівник)
* На основі накопиченого датасету тренується спеціалізована мета-модель.
* Вона аналізує потоки збудження в реальному часі:
  * Виявляє пляшкові горла (де сигнал застряє).
  * Передбачає, де вигідно проростити новий кластер або прокласти магістральний канал зв'язку.
  * Виконує прецизійну хірургію та підрізання застарілих трактів.

## 7. Архітектурний шаблон рушія на Rust

```rust
use tokio::sync::mpsc;
use std::time::Duration;

// 1. Різноманіття функцій активації нейронів
#[derive(Clone, Copy, Debug)]
pub enum Activation {
    Linear,
    LeakyReLU,
    Sigmoid,
    SineFourier, // для періодичних та хвильових процесів
    SpikeThreshold, // спайковий пороговий інтегратор
}

// 2. Внутрішні біологічні параметри індивідуального нейрона
pub struct NeuronActor {
    pub id: usize,
    pub cluster_id: usize,
    pub potential: f32,
    pub threshold: f32,
    pub tau_decay: f32, // стала часу затухання
    pub activation: Activation,
    pub local_synapses: Vec<Synapse>,
    pub highway_out: Option<mpsc::Sender<Spike>>,
    pub rx: mpsc::Receiver<Spike>,
}

pub struct Synapse {
    pub target_id: usize,
    pub weight: f32,
    pub delay_ticks: u8,
}

pub struct Spike {
    pub source_id: usize,
    pub amplitude: f32,
}

// 3. Біла речовина: Швидкісна багатосмугова магістраль зв'язку
pub struct NeuralHighway {
    pub id: usize,
    pub from_cluster: usize,
    pub to_cluster: usize,
    pub bandwidth: usize,
    pub is_myelinated: bool,
    pub bus_tx: mpsc::Sender<Vec<Spike>>,
}

// 4. Геном системи, здатний до мутацій та росту з 1 нейрона
pub enum MorphicMutation {
    SpawnNeuron { split_synapse: (usize, usize), activation: Activation },
    FormSynapse { from: usize, to: usize, weight: f32 },
    BuildHighway { from_cluster: usize, to_cluster: usize, bandwidth: usize },
    MyelinateHighway { highway_id: usize },
    PruneWeakSynapses { min_weight: f32 },
}
```

## 8. Просторовий 2D-Рушій (Interactive Connectome Canvas)

Замість перевантаженого 3D-середовища, де вузли перекривають один одного, використовується **високоефективне 2D-середовище на базі `wgpu` / Canvas**:
1. **Топологічний вигляд:** Кластери нейронів виглядають як сяючі острови (міста), між якими натягнуті світлові кабелі різної товщини (магістральні канали).
2. **Пульсація активності в реальному часі:**
   * Під час мови Андрія видно, як імпульси біжать від аудіо-входу по головній магістралі в логіку.
   * Видно спалах збудження в кластері пам'яті під час пошуку формули.
   * Видно вихідний потік у мовному центрі.
3. **Візуальний моніторинг росту:** Дослідник у реальному часі спостерігає процес нейрогенезу — появу нових точок, проростання аксонних мостів та відмирання неефективних зв'язків.
