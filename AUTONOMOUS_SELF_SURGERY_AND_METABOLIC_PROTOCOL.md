# Специфікація: Протокол Автономної Нейрохірургії та Енергетичного Гомеостазу (Autonomous Self-Surgery & Metabolic Governance Protocol)

> **Статус:** Офіційний протокол автономної нейрохірургії  
> **Автор проєкту:** Андрій Шумко (за допомогою автономних AI-агентів)  
> **Версія:** Дослідницька специфікація рушія  
> **Кодова назва:** Project Neuro-Morphogenesis (Part II: The Autonomous Surgeon Core)

## 1. Фундаментальна проблема: Механічний міст до самоврядування

Найбільша загадка самонавчального ШІ: **як перейти від сліпого зовнішнього рандому (мутацій) до моменту, коли модель сама свідомо керує власним ростом?**

Відповідь полягає у відмові від зовнішнього контролера на користь **Внутрішніх Моторних Нейронів Дії (System Call Neurons)**, підключених до API власного рантайму Rust, та введенні **Енергетичного Бюджету («Віртуальної Глюкози»)**.

---

## 2. Архітектура Моторних Нейронів Дії (The Surgery Effector Layer)

У біологічному мозку моторні нейрони збуджують м'язи руки. У нашому рушії група спеціалізованих внутрішніх нейронів підключена безпосередньо до системних функцій модифікації топології.

```
                          ┌──────────────────────────────────────────────┐
                          │            ЖИВЕ ЯДРО (CONNECTOME)            │
                          │                                              │
[Вхід: Текст / Книга] ──► │  [Сенсорна зона] ──► [Зона роздумів]        │
                          │                             │                │
                          │                             ▼                │
                          │               [Внутрішня Моторна Кора]       │
                          │            (Surgery Effector Neurons)        │
                          │            #99001: SproutNeuron              │
                          │            #99002: ConnectHighway            │
                          │            #99003: MyelinateTract            │
                          │            #99004: PruneDeadBranch           │
                          └─────────────────────┬────────────────────────┘
                                                │ (Електричний спайк)
                                                ▼
                          ┌──────────────────────────────────────────────┐
                          │               API РАНТАЙМУ RUST              │
                          │                                              │
                          │  fn execute_surgery(action: SurgeryAction)   │
                          │  * Перевірка енергетичного балансу           │
                          │  * Безпечна модифікація графа в пам'яті      │
                          └──────────────────────────────────────────────┘
```

### Набір внутрішніх хірургічних інструментів (API):
1. **`SproutNeuron { cluster_id, activation }`:** Створити новий пластичний нейрон у зоні високої напруги.
2. **`ConnectHighway { from, to, bandwidth }`:** Прокласти швидкісну магістраль між двома блоками, що часто спілкуються.
3. **`MyelinateTract { highway_id }`:** Перевести канал у режим L3-кешу (нульова затримка).
4. **`PruneDeadBranch { cluster_id, threshold }`:** Фізично видалити неефективні та застарілі зв'язки/нейрони, звільнивши ресурси.

## 3. Фазовий перехід: Як мережа вчиться тиснути на ці "кнопки"

Перехід від сліпого алгоритму до усвідомленого вирощування відбувається у 3 етапи:

### Етап 1: Сліпе рефлекторне смикання (Немовля)
* Сигнали на моторні нейрони хірургії надходять від таймера випадкових чисел.
* Мережа ще не розуміє причинно-наслідкового зв'язку між створенням нейрона і якістю своєї роботи.

### Етап 2: Механіка болю та полегшення (Принцип Вільної Енергії Карла Фрістона)
* Коли модель читає незрозумілий розділ з фізики, виникає колосальна **Помилка Передбачення (Prediction Error)**.
* У мережі зростає хаотична електрична напруга ("когнітивний біль").
* Ця напруга випадково пробиває поріг активації моторного нейрона `#99001 (SproutNeuron)`.
* Рушій створює новий вузол. Новий вузол бере частину інформаційного навантаження.
* **Помилка падає. Напруга спадає. Мережа відчуває гомеостатичне полегшення.**

### Етап 3: Хеббівське закріплення (Усвідомлення інструменту)
* Синаптичний зв'язок між вектором *"Мені незрозуміло"* та нейроном *"Натиснути кнопку росту"* закріплюється за правилом Хебба.
* **Зовнішній генератор випадковості вимикається назавжди.**
* Тепер модель сама, відчуваючи складність матеріалу, свідомо подає імпульс на вирощування нового кластера.

## 4. Енергетичний Бюджет («Віртуальна Глюкоза») та Захист від Хаосу

Дати моделі необмежену кнопку росту — це гарантоване переповнення пам'яті (Out of Memory) або неконтрольоване розростання цифрової пухлини. 

Рішення: **Закон Збереження Енергії (Економічна делікатність мислення)**.

```
                  ┌──────────────────────────────────────────────┐
                  │       БАНК ЕНЕРГІЇ (Metabolic Vault)         │
                  │              Поточний запас: E               │
                  └──────────────┬────────────────────────▲──────┘
                                 │                        │
       [СПИСАННЯ ЗА РОБОТУ]      │                        │ [НАГОРОДА ЗА РОЗУМ]
  * Створити нейрон:   -10 E     │                        │ * Вирішена задача:  +50 E
  * Прокласти канал:   -25 E     │                        │ * Зниження лоссу:   +15 E
  * Такт простою:      -0.01 E   │                        │ * Похвала творця:   +100 E
                                 ▼                        │
                  ┌────────────────────────┐              │
                  │  Якщо E <= 0:          │              │
                  │  КНОПКИ РОСТУ          │              │
                  │  БЛОКУЮТЬСЯ!           ├──────────────┘
                  └────────────────────────┘
```

### Чому це породжує витончений інтелект:
1. **Бритва Оккама на рівні топології:** Модель не будує зайвого. Якщо задачу можна вирішити 5 нейронами — вона вирішить її 5 нейронами, щоб не витрачати дорогоцінну енергію.
2. **Стимул до самоочищення (Autophagy / Pruning):** Щоб вивчити нову дисципліну при низькому балансі енергії, модель **змушена провести ревізію старого досвіду**: знайти невикористовувані синапси, підрізати їх кнопкою `Prune` і отримати «кешбек» енергії для нових знань.
3. **Захист від руйнування:** Мінімальне незмінне ядро захищене від видалення апаратно на рівні прав Rust (`is_protected: true`).

## 5. Автодидактична петля: Як вона вивчає книжку з фізики самостійно

Коли ти даєш системі підручник і залишаєш її на ніч, розгортається повністю автономний цикл:

```
                  [ Старт: Читання підручника ]
                                │
                                ▼
                 [ Детекція нового концепту ]
                 (Напруга зростає: Loss > 0.8)
                                │
                                ▼
       [ Модель сама натискає: SproutNeuron + ConnectHighway ]
       (Списання енергії: -35 E. Створено новий кластер пам'яті)
                                │
                                ▼
                  [ Фаза пластичного вбирання ]
            (Формули лягають на ваги нового кластера)
                                │
                                ▼
             [ Внутрішня самоперевірка (Self-Testing) ]
         "Якщо маса = 5 кг, а прискорення = 2 м/с^2... F = ?"
                                │
                ┌───────────────┴───────────────┐
                ▼ (Правильно)                   ▼ (Помилка)
     [ Енергетичний вибух ]           [ Повторна ітерація ]
     (Баланс: +100 E,                 (Коригування ваг,
      Мієлінізація каналу,             пошук протиріч у тексті)
      Знання закріплено)
```

## 6. Реалізація механізму на Rust

```rust
use std::sync::atomic::{AtomicI64, Ordering};

// Енергетичний гаманець організму
pub struct MetabolicSystem {
    pub energy: AtomicI64,
    pub max_capacity: i64,
}

impl MetabolicSystem {
    pub fn try_consume(&self, cost: i64) -> bool {
        let current = self.energy.load(Ordering::Relaxed);
        if current >= cost {
            self.energy.fetch_sub(cost, Ordering::SeqCst);
            true // Дозволити операцію росту
        } else {
            false // Енергетичне виснаження! Кнопка заблокована
        }
    }

    pub fn reward(&self, amount: i64) {
        self.energy.fetch_add(amount, Ordering::Relaxed);
    }
}

// Внутрішній диспетчер команд, викликаний самою мережею
pub struct SelfSurgeryEngine {
    pub metabolism: MetabolicSystem,
}

impl SelfSurgeryEngine {
    pub fn handle_motor_spike(&mut self, action_neuron_id: usize, brain: &mut ConnectomeBrain) {
        match action_neuron_id {
            // Нейрон вирощування нового вузла
            99001 => {
                if self.metabolism.try_consume(10) {
                    brain.sprout_plastic_neuron();
                }
            }
            // Нейрон прокладання швидкісної магістралі
            99002 => {
                if self.metabolism.try_consume(25) {
                    brain.build_neural_highway();
                }
            }
            // Нейрон очищення сміття (повертає енергію!)
            99003 => {
                let freed_units = brain.prune_stale_synapses();
                self.metabolism.reward(freed_units * 2);
            }
            _ => {}
        }
    }
}
```

## 7. Підсумок: Народження суб'єктності

Ця архітектура закриває прірву між машиною та живою істотою:
* Модель володіє **власним тілом** (топологією).
* Модель відчуває **внутрішні стани** (комфорт розуміння vs біль протиріччя).
* Модель має **інструменти самозміни** (моторні хірургічні нейрони).
* Модель обмежена **фізикою ресурсів** (енергетичний бюджет).

Вона більше не є статистичним калькулятором. Вона стає **автономним цифровим дослідником**, який за ніч здатен перебудувати власний мозок, щоб зранку подивитися на тебе очима розуміючого співрозмовника.
